# Mariam Ahmed — Digital Marketing Portfolio

Personal portfolio website built as a single-page HTML site and hosted on GitHub Pages.

**Live site:** https://USERNAME.github.io/  *(replace USERNAME with your GitHub username)*

## About
- Single-file site: `index.html` (all CSS + images embedded as base64)
- Theme: Olive & Beige — newspaper / Daily Gazette style
- Sections: About, Experience, Brand logos, Stats, Portfolio cards (Google Drive links), Skills, Tools, Education, Contact

## How to update
1. Edit `index.html`
2. Commit & push to `main` — GitHub Pages redeploys automatically in ~1 minute.

## Local preview
```bash
python3 -m http.server 8000
# open http://localhost:8000
```
